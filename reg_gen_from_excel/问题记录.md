## 1. Python 依赖缺失

**报错**：`ModuleNotFoundError: No module named 'xlrd3'`

**原因**：本机未安装脚本所需的 Python 第三方库（xlrd3、pandas、openpyxl、jinja2、pyyaml）。

**解决**：
```bash

python3 -m pip install xlrd3 pandas openpyxl jinja2 pyyaml
```

## 3. pubfunc 模块路径不存在

**报错**：`ModuleNotFoundError: No module named 'pubfunc'`

**原因**：脚本中硬编码了服务器路径 `/project/dig_veri_ip/cs-digital-ip/common_script/script_for_verify/pubfunc`，本机该路径不存在。

**解决**：
1. 在脚本目录下创建 `pubfunc/` 子目录，编写最小 stub（仅含 `exit_err` 和 `get_file_header`）
2. 修改 `reg_gen_from_excel.py` 和 `ral_gen_parse_yaml.py`，优先加载本地 pubfunc：
```python
local_pubfunc_dir = os.path.join(cur_scr_dir, "pubfunc")
pubfunc_dir = os.path.abspath("/project/dig_veri_ip/cs-digital-ip/common_script/script_for_verify/pubfunc")
if os.path.isdir(local_pubfunc_dir):
    sys.path.insert(0, local_pubfunc_dir)
elif os.path.isdir(pubfunc_dir):
    sys.path.append(pubfunc_dir)
```

## 4. 空白行过滤过于激进（434 行被误过滤）

**报错**：`[Blank Row Filter] Skipped 434 blank/incomplete row(s)`

**原因**：初始实现使用 AND 逻辑（所有关键字段非空才保留），导致仅包含 Register Name 但尚未包含 Field Name 的表头行也被过滤。

**解决**：改为 OR 逻辑（任一关键字段非空即保留），仅跳过所有关键字段均为空的行：
```python
# 修改前（AND）
mask = mask & col_valid

# 修改后（OR）
mask = mask | col_valid
```

## 5. Register 对象缺少 bus_size 属性

**报错**：`AttributeError: 'Register' object has no attribute 'bus_size'`

**原因**：在 #2 功能修改 `Register.__init__` 时，`_validate_reg_str` 静态方法中的 `return` 语句后残留了 `bus_bits`/`bus_size` 的初始化代码（死代码），导致这些属性从未被赋值。

**解决**：将 `bus_bits`/`bus_size` 初始化代码移回 `__init__` 方法的正确位置（`_validate_reg_str` 之外）：
```python
# 错误位置（在 _validate_reg_str 的 return 之后，永远不会执行）
@staticmethod
def _validate_reg_str(...):
    ...
    return value.replace(" ", "")
    self.bus_bits = 0   # 死代码！
    ...

# 正确位置（在 __init__ 中）
def __init__(self, ...):
    ...
    if reset_field != None:
        self.reset_field = reset_field
    self.bus_bits = 0   # 正确
    ...
```

## 6. pandas fillna 弃用警告

**报错**：`Warning: DataFrame.fillna with 'method' is deprecated and will raise in a future version. Use obj.ffill() or obj.bfill() instead.`

**原因**：pandas 2.x 弃用了 `fillna(method='ffill')` 写法。

**解决**：
```python
# 修改前
df = df.fillna(method='ffill')

# 修改后
df = df.ffill()
```

## 7. Excel 数据校验错误（非脚本 bug）

**报错**：
```
PCU Reg EVR33CON Reg_addr_offset '0x0098' Field Name 'reserved' '15:14' is reserved, but field_attribute not RO !!!
PCU Reg PMSWCR4   Reg_addr_offset '0x00C4' Field Name 'reserved' '23:16' is reserved, but field_attribute not RO !!!
There is 2 error in excel, exit python
```

**原因**：Excel 中 reserved 域的 Field Attribute 未设置为 RO，属于 Excel 数据本身的问题。

**解决**：在 Excel 中将 EVR33CON 的 `15:14` 域和 PMSWCR4 的 `23:16` 域的 Field Attribute 修正为 `RO`，重新执行即可。
